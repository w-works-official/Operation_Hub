# 검토한 수정본 부분 내보내기 — 2026-09-08

## 변경
- 안전검사를 통과한 수정안만 내보내기 준비 RPC에 전달한다.
- 불완전·충돌·검증 실패·삭제/상태 변경된 수정안은 제외한다. 원본이나 연결 코드를 임의 변경하지 않는다.
- 선택한 판매처/필터/SKU/수정안 ID 범위를 유지하며 검증 후 같은 ID를 다시 조회한다.
- 제외 건수/사유 및 최대 50건을 화면에 표시한다. 전체 제외 목록은 독립 CSV 및 정상 파일 ZIP에 포함한다.
- 원본 행 검증에서 추가 제외된 항목과 준비 RPC에서 차단된 항목도 같은 목록에 포함한다.
- 전부 제외된 경우 파일 생성 성공으로 표시하지 않으며 화면에서 제외 CSV를 받을 수 있다.
- 준비 RPC가 실패한 실제 사유를 읽어 표시하며 '원본 위치 확인 불가 0건'으로 덮어쓰지 않는다.
- 파일 완료 후 화면 새로고침/다운로드 오류가 완료 이력을 실패로 덮어쓰지 않게 한다.

## DB 변경
- 적용 마이그레이션: 20260908053005_operations_hub_export_validation_safety_guard_v1
- validate_operations_hub_changes(bigint[])는 source_channel이 있는 불완전·충돌 수정안을 검토 완료로 승격하지 않는다.
- 기존 SECURITY INVOKER, 함수 권한, search_path 유지. 기존 수정안 일괄 상태 보정/삭제 없음.
- 기존에 잘못 validated가 된 수정안도 새 프론트에서 안전 상태로 제외한다.
- 보안 점검 67개 기존 항목, 신규 cache_key 0개.
- 원본 파일과 연결 코드는 수정/삭제하지 않았다.
