피킹 보조 기능과 현황을 분리해서 관리합니다.

출력 · 정렬

피킹 순서와 출력 파일을 만듭니다. 재고반영 수량은 일반 피킹보관·미송서랍과 오늘 주문제작 주문수량을 SKU별로 분리합니다.

조회 · 관리

현재 작업 상태와 CS 내역을 조회하는 기능입니다.

상품 사진 관리

파일명은 셀피아 SKU입니다. 공용은 8601.jpg, 지정 옵션은 8601-[1][3].jpg, 연속 옵션은 8601-[1-10].jpg입니다. 전체를 { }로 감싼 {8601}.jpg 또는 {8601-[1-10]}.jpg는 일반 사진보다 먼저 적용됩니다.

여러 장 업로드
여기에 상품 사진 여러 장을 드래그 JPG · PNG · WEBP / 정확 SKU · 공용 prefix · 옵션 범위 지원
개별 옵션 사진이 공용 prefix 사진보다 우선합니다.
업로드할 사진을 선택하거나 드래그하세요.

사진 라이브러리

사진은 클릭해 확대하고, 왼쪽 위 체크로 여러 장을 선택할 수 있습니다. 선택한 사진 중 하나를 우클릭하면 한 번에 삭제할 수 있으며, 일반 우클릭에서는 이름 변경·삭제를 할 수 있습니다. { }로 감싼 파일은 최우선 사진이며, 그 안에서는 전용 → 묶음 → 범위 → 공용 순서가 유지됩니다. 이름 변경은 새 이름으로 저장한 뒤 원본을 삭제하므로 정상 완료 시 복제본이 남지 않고, 삭제는 파일과 연결을 바로 제거합니다.

사진 목록을 불러오는 중입니다.
